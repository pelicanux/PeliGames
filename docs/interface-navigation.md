# Navegação nas configurações

Ao abrir uma configuração por um atalho nos detalhes de um jogo, use **Biblioteca** ou feche as configurações para retornar ao jogo e à aba de origem. A lembrança vale para a sessão atual; mudar de jogo inicia outro contexto.

Nas categorias com abas, selecione a pílula correspondente ao recurso. Use **Buscar**, à direita das abas, para localizar configurações em outras categorias. Os resultados agrupam as opções relacionadas ao termo pesquisado.

## Benchmarks

Na área de monitoramento, use a aba de comparação para selecionar os registros disponíveis e comparar os resultados. As medições dependem da coleta estar configurada para o jogo.
