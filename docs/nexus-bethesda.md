# Mods de jogos Bethesda

Adicione a instalação compatível à biblioteca Nexus e abra sua aba **Mods**. Confira os requisitos de cada mod antes de instalar: alguns exigem script extender, alterações de INI ou ferramentas externas.

## Instalar e organizar

1. Selecione o jogo e importe o arquivo ou escolha o mod no catálogo.
2. Confira as opções do instalador FOMOD, quando disponível, e os destinos apresentados.
3. Ative o mod e confira conflitos e a ordem dos plugins na interface.
4. Para desfazer uma instalação, use o gerenciamento do mod para restaurar os arquivos preservados.

Pacotes podem incluir arquivos BSA/BA2, plugins e ajustes de INI. O tratamento depende do módulo e da edição do jogo. ENB, carregadores de DLL e script extenders podem exigir instruções adicionais do autor; não trate versões de edições diferentes como intercambiáveis.

No Fallout New Vegas, confirme qual instalação foi adicionada antes de gerenciar mods. Prefixos e executáveis devem corresponder à instalação selecionada.

Consulte a [lista de jogos suportados](supported-games.md) para os limites de cada módulo. Suporte do gerenciador não garante compatibilidade de todo mod, runner ou versão do jogo.
