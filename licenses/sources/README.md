# Fontes das dependências MPL-2.0

Arquivos `.crate` originais, sem modificações, correspondentes às versões fixadas no `src-tauri/Cargo.lock`: cssparser 0.37.0, cssparser-macros 0.7.1, dtoa-short 0.3.5, option-ext 0.2.0 e selectors 0.38.0.

São arquivos tar gzip publicados no crates.io. Podem ser extraídos com `tar -xzf arquivo.crate`. As declarações de licença e avisos nos arquivos-fonte foram preservados. Estas cópias atendem apenas às fontes desses crates; não são as fontes das bibliotecas nativas incluídas no AppImage.
